# My Journal (Vercel, no accounts)

Static site, no build step, no database. Your journal is stored in the browser on your device.

## Deploy
1. Upload these files to a GitHub repo (index.html at the top level).
2. Vercel > Add New > Project > import the repo. Preset: Other. No build command. Deploy.

## Keep your data safe
Open the Today tab > Your data > Download backup every week or so. Restore it from the same card on any device.
